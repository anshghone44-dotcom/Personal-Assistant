"An intelligent personal space that you can talk to."

- a SaaS dashboard

"The interface should disappear and the conversation should become the product."

7. VOICE ORB
==================================================

Create a reusable:

VoiceOrb component.

This is the main visual identity of the product.

The VoiceOrb should be visually sophisticated.

Do NOT create a simple microphone circle.

Create a soft luminous orb with subtle depth.

Use:
- radial gradients
- blur
- layered opacity
- subtle light
- animation
- audio-reactive placeholder behavior

Create six states.

------------------------------------------
IDLE
------------------------------------------

Appearance:

Small luminous orb.

Animation:

Slow breathing.

Approximately:

scale:
1 → 1.025 → 1

Duration:
4 seconds

Very subtle.

------------------------------------------
LISTENING
------------------------------------------

Orb becomes slightly larger.

Outer rings appear.

Create subtle animated audio waves.

Use mock audio values for now.

Animation should react smoothly.

Text:

"Listening..."

------------------------------------------
THINKING
------------------------------------------

Orb remains stable but develops subtle internal movement.

Use slow radial movement.

Text:

"Thinking..."

Do NOT use a generic loading spinner.

------------------------------------------
SPEAKING
------------------------------------------

Orb responds to simulated audio amplitude.

Use:

scale
opacity
outer ring movement

Text:

"Speaking..."

------------------------------------------
SUCCESS
------------------------------------------

When an interaction completes:

Create one elegant pulse.

Then return to idle.

------------------------------------------
ERROR
------------------------------------------

Use:

small horizontal movement

subtle opacity change

Text:

"Something went wrong."

Do not use aggressive red screens.
